# Frontend

React-клиент игры «Воздушный Шар».

```sh
npm install
npm run dev
```

Для локальной разработки backend должен быть доступен на `http://localhost:8080`.
Vite автоматически проксирует к нему запросы `/api` и WebSocket `/ws`.

Авторизация и игровое состояние хранятся на backend. В браузере сохраняется только токен сессии и выбранная тема.
