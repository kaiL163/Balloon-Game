# Воздушный Шар

Рабочий frontend-прототип на React, TypeScript, Vite и React Router, без backend.

## Запуск и проверки

```sh
npm install
npm run dev
npm test
npm run build
```

`npm run preview` — просмотр production-сборки. Сервер должен возвращать `index.html`
для клиентских маршрутов `/game` и `/result` (SPA fallback).

## Игровой цикл

- `/` — существующая BetPage, правила и история. GREEN — 9 уровней, RED — 12.
- Ставки: 100, 150, 250, 400 бонусов. Ставка списывается один раз при старте.
- `/game` — полёт с плавным ростом коэффициента на 0.2 в секунду. Первый уровень — 1.5,
  далее каждые 0.5 коэффициента. Подбор бустера не меняет скорость полёта и момент crash.
- За уровень — 10 игровых очков. Бустер определяется ставкой: 100 — без бустера, 150 — x2, 250 — x3, 400 — x4. При x2–x4 сундук размещается на случайном уровне 2–N,
  умножает коэффициент выплаты и добавляет 20 × booster очков. При cashout раньше
  бустера он становится MISSED.
- Cashout доступен после первого уровня. Фиксируется коэффициент с точностью
  до сотых и выплата `ставка × коэффициент`, округлённая до сотых бонуса.
  Выплата начисляется сразу и повторно не меняется. После cashout шар ускоряется до краша примерно за 2 секунды, продолжая набирать очки. Затем взрыв и переход к итогам за 1.4 секунды.
- Crash задан при создании раунда в MockGameApi. В совпавшей точке crash имеет
  приоритет над cashout. Через 1.4 секунды анимации открывается `/result`.
- На результате: WIN/LOSE, ставка, cashout, crash, очки и случайный сувенир
  Balloon / Cloud / Bird / Trophy. Сувенир не меняет бонусный баланс.
- «Играть снова» возвращает к выбору шара. Возврат к ставкам также происходит после 10 секунд бездействия;
  движение указателя, нажатия, клавиатура и прокрутка сбрасывают таймер.

## Демо-сценарии

- `/game?scenario=win`: ставка 100, авто-cashout 1.60x, crash 3.20x.
- `/game?scenario=crash`: ставка 100, crash 1.30x до первого уровня.
- `/game?scenario=booster`: ставка 250, бустер x3 на уровне 2, плавный коэффициент,
  авто-cashout с коэффициентом выплаты 6.45x, crash 2.80x.

Демо использует общий баланс. При нехватке добавляется только сумма, необходимая
для ставки; это объяснено в «Тестовых полётах». Незавершённый раунд имеет приоритет
над новой ссылкой. Автопилот подписан на игровом экране; cashout можно нажать вручную.

## Данные и устройство

В localStorage под ключом `balloon-game-v1` сохраняются `bonusBalance`, `gamePoints`,
тема, текущий раунд и история. Очки и бонусы — отдельные значения. Текущий раунд
восстанавливается при перезагрузке; расчёт по времени учитывает фоновые вкладки.
Баланс, начисленные очки и история записываются вместе. Повторный cashout и повторное
завершение не дублируют начисления или награды. В конце истории остаются 6 старых
демо-примеров, не участвующих в расчётах. Для чистого профиля удалите только этот ключ
через инструменты разработчика браузера.

- `src/pages` — маршруты.
- `src/components` — существующие модальные окна и компоненты игры в `game/`.
- `src/hooks` — обновление полёта, короткие эффекты, таймер бездействия.
- `src/api/MockGameApi.ts` — генерация, сохранение, баланс и завершение.
- `src/api/flightEngine.ts` — порядок событий уровня, booster, cashout и crash.
- `src/types` — типы и контракты данных.
- `src/styles` — прежний стиль плюс адаптивные игровые экраны.
- `tests/game.test.mjs` — проверки денег, событий, восстановления и демо-сценариев.

Это локальный прототип, не защищённый от редактирования данных в браузере.
